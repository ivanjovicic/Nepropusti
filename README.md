# NePropusti

## Status

**VALIDATE BEFORE BUILDING**

NePropusti is currently a validation-first product thesis, not an authorized super-app build.

The leading hypothesis is:

> **A structured Watch platform where users or partners define a condition, NePropusti observes trusted sources, detects a meaningful state change, verifies it, and alerts only when action becomes worthwhile.**

## Current leading wedge

**Commerce Watch / Price Truth**

## Current leading product shape

**Embedded Watch Button + Hybrid B2C/B2B2C**

## Secondary validation wedge

**Sport + where-to-watch** is tested as a retention wedge, not as a live-score product.

Detailed strategy and validation documentation will live under `docs/`.
