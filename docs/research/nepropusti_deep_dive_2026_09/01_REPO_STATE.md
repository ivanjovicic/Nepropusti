# Repository State

## Current main truth

NePropusti is explicitly **pre-MVP**.

Current canonical loop:

`watch -> observe -> verified transition -> useful alert -> action`

Current repository authorizes:
- desk research;
- Commerce Watch user validation;
- Embedded Watch partner validation;
- low-cost sports where-to-watch concierge.

It explicitly blocks full implementation until validation gates pass.

## Existing strengths

The repository governance is strong:
- triggers, not categories;
- no super-app first;
- open data is input advantage, not moat;
- target-price alone is not differentiation;
- generic monitoring is fallback only;
- partner thesis has real kill thresholds;
- monetization requires real money, not survey intent.

## Current hypotheses challenged by this deep dive

### Commerce Watch / Price Truth
Still useful as a source of user problems, but **too broad as the leading wedge** after Tprice and existing price trackers.

### Embedded Watch
Still the best product-shape hypothesis, but it must be reframed as:
`merchant-distributed intent recovery`
rather than “we own every user's cross-site identity from day one.”

### Sport
Useful retention adjacency, not first business.

## Implementation state

No production platform should be inferred from the documentation.
This deep dive does not authorize product code.
