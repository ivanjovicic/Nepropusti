# Moat, Network Effect and Copy Test

## Current moat

None.

## Potential moat

- embedded partner network;
- portable Watch identity;
- trusted state/action history;
- partner conversion attribution;
- privacy-safe demand graph;
- integration/reputation switching cost.

## Not moat

- open price data;
- price history;
- email/push;
- target price;
- restock primitive;
- web crawling;
- generic comparison catalog.

## Network-effect audit

### More partners -> more user watches
**Distribution effect**, plausible.

### More watches -> better merchant demand insight
**Data scale effect**, plausible.

### Better demand insight -> more merchant ROI
Plausible, must be measured.

### More merchant ROI -> more partners
Potential flywheel, not proven.

This is not yet a network effect.

## Copy tests

### Tprice adds advanced alerts
Price thesis weakens further. Restock/partner integration may survive.

### Idealno/ePonuda adds restock
Cross-site identity/merchant embedded layer must still add value.

### Merchant CRM adds perfect alerts
NePropusti survives only if portability/cross-channel/demand network matters.

### Google adds Serbia product tracking
Consumer destination thesis collapses further.

### Ticket platform adds lifecycle alerts
Ticket wedge becomes partner/API rather than destination.

## Defensibility rule

A feature available as a €49 plugin cannot be the moat.
