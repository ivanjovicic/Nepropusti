# Sports Where-to-Watch

## User job

Not live score.

> Tell me when the event is and where I can legally watch it in Serbia.

## Public data evidence

Current public schedules such as MojTV expose:
- Arena Sport channels;
- Sport Klub channels;
- start times;
- sports/event names;
- reminders.

LiveSoccerTV also provides territory/channel schedules.

This proves that information exists.

## Blocking unknown

It does **not** prove:
- API availability;
- commercial redistribution rights;
- correction SLA;
- stable entity IDs;
- streaming-right details.

## Business weakness

Who pays is unclear.

Possible:
- publisher/club for engagement;
- broadcaster/streamer affiliate;
- consumer premium.

None is proven.

## Recommendation

Keep NP-VAL-004 as low-cost concierge.

Do not automate a broadcaster database until:
- reuse rights are clear;
- users show recurring action;
- payer/strategic role is clearer.

## Score implication

Sport may improve retention, but currently reduces business focus if treated as co-primary wedge.
