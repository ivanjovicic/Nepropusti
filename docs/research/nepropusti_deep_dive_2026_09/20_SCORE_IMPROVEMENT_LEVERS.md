# Score Improvement Levers

Full matrix:
`data/score_improvement_levers.csv`

## Top five highest-information activities

### 1. 20 merchant interviews + 3 real surfaces
Changes:
- distribution;
- differentiation;
- WTP;
- operating burden.

### 2. One size/restock pilot with conversion attribution
Changes:
- problem severity;
- trigger choice;
- unit economics;
- partner value.

### 3. Paid pilot request
Changes:
- WTP;
- time to revenue;
- bootstrap score.

### 4. Merchant webhook/feed integration test
Changes:
- data burden;
- technical risk;
- support burden.

### 5. Portable identity test after first delivered value
Changes:
- retention;
- moat;
- cross-site thesis.

## Do not try to improve score by adding features

The following do not count as evidence:
- more categories;
- native app;
- bigger scraper;
- AI recommendations;
- dashboard;
- social feed.

Only behavior, partner publication, reliability and payment materially improve the business score.
