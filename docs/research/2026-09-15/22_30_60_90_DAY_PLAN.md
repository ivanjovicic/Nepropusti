# 30 / 60 / 90 Day Plan

## Days 1–30 — prove the problem and product shape

Week 1:
- audit 10–15 open price datasets;
- select 20 partner prospects;
- interview 15 commerce users;
- interview 10 sports users;
- build clickable hosted Watch prototype, no production platform.

Week 2:
- pitch partner widget to first 10 partners;
- run manual commerce Watch with first cohort;
- map 5 sports entities + broadcast sources;
- document source/reuse rights.

Week 3:
- expand to 50 commerce users;
- start 4-week sports concierge;
- pitch remaining partners;
- measure watch-creation funnel.

Week 4:
- G1/G3 interim review;
- kill or refine proposition;
- do not add verticals because results are weak.

## Days 31–60 — prove alert quality and repeated action

- automate only the source pipeline needed for successful pilot;
- keep human QA where necessary;
- run first embedded/hosted partner pilots;
- measure alert correctness and action;
- conduct verified-giveaway micro-test only if bandwidth permits;
- start real B2B pricing conversations.

Decision at day 60:
- commerce+B2B2C;
- sports-first;
- white-label/API pivot;
- stop.

## Days 61–90 — first narrow monetization

If gates pass:
- productionize narrow rule/watch core;
- onboard 3–5 partners;
- ask for real paid plan / qualified-action agreement;
- establish first attributable conversion model;
- prepare MVP backlog.

If gates fail:
- do not build a super-app as rescue.
