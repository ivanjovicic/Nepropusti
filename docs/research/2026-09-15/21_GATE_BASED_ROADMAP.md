# Gate-Based Roadmap

## G0 — Desk due diligence
**Status: PASS for research baseline**

Output: current package.

## G1 — Commerce wedge validation
Test 50–100 real watchers.
Pass only with watch creation + useful trigger actions + acceptable error rate.

## G2 — Sports wedge validation
Test narrow where-to-watch use case for 4 weeks.
Pass only if recurring behavior changes and source reliability is acceptable.

## G3 — Product-shape / partner validation
Pitch 20 partners.
Pass candidate: >=5 commitments, >=3 live pilots.

## G4 — Alert-quality proof
Shadow/real QA.
Set explicit maximum false/stale/duplicate alert rates.

## G5 — Retention proof
Measure week-4 retained active watchers and repeat useful actions.
Do not use installs as proof.

## G6 — Narrow MVP
Build only the winning wedge + winning distribution shape.

Likely scope if current hypothesis passes:
- user account/watchlist;
- partner-hosted Watch setup;
- commerce observations/history;
- rule engine;
- alert policy;
- web/email/Telegram or push;
- partner attribution dashboard.

## G7 — Monetization
Charge real partners / activate real affiliate/CPC agreement.

## G8 — Second vertical
Only if first wedge retention and economics work.
Most likely sports.

## G9 — Native mobile
Only if web/channel data proves mobile-specific retention value.

## G10 — Regional expansion
Only after repeatable Serbia partner acquisition and source operations.
