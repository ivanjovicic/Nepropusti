# Events & Ticket Alerts

## Jobs worth testing

- artist/venue event announced;
- tickets go on sale;
- additional inventory appears;
- event rescheduled/cancelled;
- reminder;
- selected local/family events.

## Competitive reality

Bandsintown already demonstrates mature lifecycle marketing: announcement, on-sale, one-month, one-week and one-day alerts. It lets users follow venues/festivals and distributes event data into other ecosystems.

Local ticket sellers already own checkout and inventory.

## Implication

NePropusti should not start by becoming an event directory or ticket marketplace.

Potential role:
- cross-organizer watch rules;
- embedded Watch button;
- partner return-traffic engine;
- selected high-friction local discovery category.

## Calendar is complementary

AddEvent demonstrates that embedded `Follow Calendar` works as a distribution pattern. But external calendar synchronization may lag (e.g. Google can take 12–24h for subscribed feeds), so calendar is unsuitable as the only channel for urgent ticket/status changes.

## Recommended first event test

Choose ONE:
- concert ticket/on-sale alerts; or
- family weekend events in one city.

Do not test “all events”.
