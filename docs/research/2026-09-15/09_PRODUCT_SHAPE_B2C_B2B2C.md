# Product Shape Tournament

## Winner: Embedded Watch Button

The strongest product shape is not currently a native destination app.

Potential flow:

`Partner page -> [Watch] -> NePropusti rule -> condition triggers -> alert -> return to partner -> measurable action`

## Why

- partner already owns traffic;
- user creates watch at moment of intent;
- transaction stays with partner;
- partner gets attributable return traffic;
- NePropusti accumulates cross-partner watch identity;
- consumer watchlist can emerge from real intent rather than cold onboarding.

## Runner-up: Hybrid B2C + B2B2C

A consumer watchlist remains valuable as the control center, but distribution should be embedded wherever possible.

## Browser extension

Useful validation/acquisition tool, especially for unsupported sites. It is not the strongest initial business because Visualping/Distill/Honey already prove deep generic/browser capability and extension permissions add trust/privacy friction.

## API / white label

Strong later B2B path after the core watch/state engine is proven.

## MCP

Good future control surface, not MVP.
