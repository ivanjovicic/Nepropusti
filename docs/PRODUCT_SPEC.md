# Product Spec — Validation Baseline

## Status

Pre-MVP hypothesis. Full implementation is not authorized.

## Product thesis

NePropusti helps users stop repeatedly checking websites by watching trusted structured state for them.

`watch -> observe -> verified transition -> useful alert -> action`

## Primary job under validation

> **Tell me only when a condition I care about becomes true, with enough trust/context that I can act immediately.**

## First wedge hypothesis

### Commerce Watch / Price Truth

User can watch target price, price-history condition, restock/availability, and selected verified deal conditions.

NePropusti must not become a generic comparison catalog as the first product.

## Product-shape hypothesis

### Embedded Watch Button

A merchant/site places a Watch control at the moment of intent. NePropusti owns the user rule, alert policy and cross-site watchlist; the partner retains the transaction.

## Secondary wedge

Sport + where-to-watch is tested for retention. Do not build live scores.

## North Star candidate

**Useful Alert Actions per Weekly Active Follower**

See root README and `OPPORTUNITY_BACKLOG.md`.
