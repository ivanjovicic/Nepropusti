# Canonical Roadmap

## Phase 0 — Due diligence
**Done:** desk-research package completed.

## Phase 1 — Commerce Watch validation
**NOW**
- audit open-price data;
- recruit 50–100 users;
- test target-price, price-truth and restock rules;
- measure watch creation, trigger quality and action.

## Phase 2 — Embedded Watch / partner validation
**NOW in parallel**
- select 20 partner prospects;
- use hosted/no-code Watch surface first;
- measure actual pilot commitments and published integrations.

## Phase 3 — Sports concierge validation
**NOW, lower-cost parallel track**
- narrow teams/players;
- manually/semiautomatically validate where-to-watch workflow;
- solve data-rights/freshness before automation.

## Phase 4 — Alert-quality proof
Automate only enough of winning pilot sources to measure reliability.

## Phase 5 — First monetization
Charge real partners / activate real commercial agreement.

## Phase 6 — Narrow MVP
Only after G1–G5 sufficiently pass.

## Phase 7+ — Optional expansion
Second vertical -> G8
Native -> G9
Region -> G10

A failed gate can cause stop, split-brand decision, or pivot.
