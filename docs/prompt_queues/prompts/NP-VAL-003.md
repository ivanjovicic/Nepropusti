# NP-VAL-003 — Embedded Watch Partner Validation

## Goal
Test whether B2B2C distribution is real.

## Prospects
20 highly relevant merchants/event/ticket/content partners.

## Pitch
“We return users exactly when the condition they requested becomes true, and measure the return/action.”

Do not sell generic notification infrastructure.

## Pilot forms
1. hosted Watch link;
2. simple embedded button/mock;
3. no custom SDK unless partner requests it.

## Required evidence
objections, current solution, integration owner, data/feed ability, ROI metric and real commitment.

## Pass candidate
>=5 credible commitments and >=3 live hosted/embedded pilots.

## Kill signal
<2 genuine commitments after 20 strong-fit pitches.
