# NP-VAL-002 — Commerce Watch User Validation

## Goal
Validate whether users create real watches and act on meaningful triggers.

## Cohort
50–100 qualified Serbian users with concrete purchase intent.

## Test separately
- exact target price;
- price-truth/history context;
- restock/availability.

## Measure
proposition understanding, watch creation, rule type, incumbent replacement behavior, useful alert action, trust and mute/stop behavior.

## Pass candidate
>=30% of qualified users create a real watch and triggered alerts generate meaningful action.

## Kill signal
<15% watch creation after clear UX, or repeated “existing tools already solve this”.

Do not build broad production UI for this test.
