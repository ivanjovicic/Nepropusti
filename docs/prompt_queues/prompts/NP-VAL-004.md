# NP-VAL-004 — Sports Where-to-Watch Concierge

## Goal
Validate whether “when + where can I watch” changes real user behavior enough to justify a sports wedge.

## Scope
50–100 users, 4 weeks, narrow entity set such as Red Star/Partizan basketball, Serbia teams, Djokovic and optionally F1.

## Alerts
fixture/time confirmation, broadcaster/stream confirmation, one reminder and meaningful change alerts.

## Measure
follows/user, search/checking replaced, alert action, week-4 retention, false/stale rate and source-rights/freshness feasibility.

## No-go
Do not implement live scores.
